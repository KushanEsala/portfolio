# SEO plan for kushanesala.me

## Implemented in this release

- Descriptive page title and search snippet focused on Kushan Esala, software engineering, research and development, Kandy, SaaS, backend systems, and AI automation.
- Canonical URL for the custom domain.
- Indexing and rich-snippet crawler directives.
- Open Graph and Twitter metadata for consistent shared-link summaries.
- `WebSite` and `Person` JSON-LD with identity, location, professional focus, LinkedIn, GitHub, and SIBA references.
- Public `robots.txt` and a canonical one-page `sitemap.xml`.
- Natural on-page wording for “software engineer in Kandy, Sri Lanka”; no hidden keyword blocks or repetitive keyword stuffing.

These phrases should be used only where they describe real work. Google does not use the meta-keywords tag, and unnatural repetition can reduce content quality.

## Manual launch steps

1. Add `kushanesala.me` as a Domain property in Google Search Console and complete the DNS TXT verification.
2. Submit `https://kushanesala.me/sitemap.xml` in Search Console.
3. Inspect `https://kushanesala.me/` and request indexing after this deployment is live.
4. Add `https://kushanesala.me/` to the LinkedIn contact section and GitHub profile so Google sees consistent identity links.
5. Review Search Console after two to four weeks for impressions, indexed status, mobile usability, and the queries that actually surface the page.

## Expectations

Technical SEO makes the portfolio crawlable and understandable, but it cannot guarantee a ranking. Branded searches such as “Kushan Esala” are the most realistic early target. Broader terms such as “software engineer Kandy” depend on indexing time, useful supporting content, external references, and competition.
